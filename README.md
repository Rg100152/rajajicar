# 🚗 RajajiCar — Midnight Neon Luxury Car Rental Platform 🌌

[![Python Version](https://shields.io)](https://python.org)
[![Flask Framework](https://shields.io)](https://palletsprojects.com)
[![Database](https://shields.io)](https://sqlite.org)
[![License: MIT](https://shields.io)](https://opensource.org)

**RajajiCar** एक प्रीमियम और लग्जरी कार रेंटल फुल-स्टैक प्लेटफॉर्म है, जिसे एक आकर्षक **Midnight Neon (Dark Mode)** थीम विजुअल एक्सपीरियंस के साथ डिजाइन किया गया है। यह एप्लीकेशन बैकएंड में **Flask (Python)** और डेटाबेस के लिए **SQLite3** का उपयोग करती है, जो उपयोगकर्ताओं को रीयल-टाइम कार बुकिंग, सिक्योरिटी ओटीपी वेरिफिकेशन, रूट एस्टीमेशन और एडवांस्ड एआई-संचालित रखरखाव चेतावनियां प्रदान करता है।

---

## 🌟 मुख्य विशेषताएं (Key Features)

*   **🌌 Midnight Neon UI (SPA):** एक ही पेज पर सीमलेस अनुभव देने वाला Single-Page Application (SPA) इंटरफेस, जो Orbitron और Montserrat फोंट्स और नियॉन लाइट्स इफेक्ट से लैस है।
*   **🏎️ Premium Fleet Management:** BMW M3 Competition, Mercedes-Benz E-Class, Porsche Carrera, और Thar 4x4 जैसी लग्जरी और एसयूवी कारों का पूरा डेटाबेस प्रबंधन।
*   **📈 Dynamic Surge Pricing AI:** लाइव डिमांड और पीक ऑवर्स के आधार पर कीमतों का डायनामिक बदलाव (जैसे: *Normal Hours 1.0x*, *Peak Demand*) जिसे एडमिन सीधे कंट्रोल कर सकता है।
*   **🛠️ Predictive Maintenance Alert:** वाहन के कुल किलोमीटर रन (`total_km_run`) के आधार पर सिस्टम ऑटोमैटिकली `URGENT` या `WARNING` रखरखाव चेतावनियां और एक्शन प्लान जेनरेट करता है।
*   **🔒 Secure Boarding (Ride OTP):** सुरक्षा सुनिश्चित करने के लिए प्रत्येक बुकिंग पर 4-डिजिट का यूनिक राइड स्टार्ट ओटीपी (OTP) जेनरेट होता है, जिसे ड्राइवर के साथ साझा करना अनिवार्य है।
*   **🗺️ Route & Fare Estimator:** दो स्थानों (अक्षांश/देशांतर) के बीच दूरी की गणना करने के लिए बैकएंड में **Haversine Formula** का उपयोग और उसी के आधार पर सटीक किराए व समय का अनुमान।
*   **🤖 AI Concierge Chatbot:** किराए की दरों, ओटीपी सुरक्षा, कैंसिलेशन पॉलिसी और लाइव ट्रैकिंग से जुड़े यूजर के सवालों का तुरंत जवाब देने वाला इन-बिल्ट चैटबॉट।
*   **🎁 Loyalty & Referral Economy:** हर बुकिंग पर पॉइंट अर्न करने का सिस्टम (₹100 खर्च पर 1 पॉइंट) और दोस्तों को रेफर करने पर +150 बोनस पॉइंट मिलने की सुविधा।

## 🏗️ डेटाबेस स्कीमा (Database Architecture)

एप्लीकेशन शुरू होते ही SQLite3 डेटाबेस स्वचालित रूप से जेनरेट होता है और डिफ़ॉल्ट डेटा के साथ सीड (Seed) हो जाता है। इसमें मुख्य रूप से 5 टेबल्स हैं:
1.  **`cars`**: वाहनों की स्थिति, प्रति दिन का किराया, हॉर्सपावर, और लाइव GPS लोकेशन स्टोर करने के लिए।
2.  **`bookings`**: बुकिंग रेफरेंस नंबर, फेयर कैलकुलेशन (बेस फेयर + 18% GST), पिकअप/ड्रॉप विवरण और OTP सेव करने के लिए।
3.  **`drivers`**: ड्राइवर रेटिंग (e.g. 4.9⭐), आधार वेरिफिकेशन स्टेटस, दैनिक कमाई और ऑनलाइन ड्यूटी आवर्स के लिए।
4.  **`settings`**: डायनामिक सर्ज मल्टीप्लायर और एक्टिव पीरियड को मैनेज करने के लिए।
5.  **`users`**: यूजर प्रोफाइल, लॉयल्टी पॉइंट्स और रेफरल कोड ट्रैक करने के लिए।

## 🚀 एपीआई एंडपॉइंट्स (API Endpoints)

यह प्लेटफॉर्म निम्नलिखित RESTful JSON APIs प्रदान करता है:

| एंडपॉइंट | मेथड | विवरण |
| :--- | :--- | :--- |
| `/api/state` | `GET` | सभी कारों, बुकिंग्स, ड्राइवरों की स्थिति और एआई मेंटेनेंस अलर्ट्स का डेटा प्राप्त करने के लिए। |
| `/api/book` | `POST` | नई कार बुक करने, रीयल-टाइम किराया कैलकुलेट करने और ओटीपी जेनरेट करने के लिए। |
| `/api/estimate_route` | `POST` | दो कोऑर्डिनेट्स के बीच दूरी (Haversine), सर्ज किराया और समय का अनुमान लगाने के लिए। |
| `/api/chatbot` | `POST` | राजजीकार एआई कंसीयज (AI Concierge) से संवाद करने के लिए। |
| `/api/admin/surge` | `POST` | एडमिन द्वारा लाइव सर्ज प्राइसिंग (Surge Multiplier) को अपडेट करने के लिए। |
| `/api/admin/car_status` | `POST` | किसी कार को सर्विसिंग से हटाकर दोबारा 'Available' करने या स्टेटस बदलने के लिए। |
| `/api/refer` | `POST` | नए मित्र को इनवाइट करने और लॉयल्टी बोनस जोड़ने के लिए। |

## ⚙️ इंस्टॉलेशन और लोकल सेटअप (Installation Guide)

प्रोजेक्ट को अपने लोकल सिस्टम पर रन करने के लिए नीचे दिए गए स्टेप्स का पालन करें:

### 1. रिपॉजिटरी क्लोन करें
```bash
git clone https://github.com
cd rajajicar
```

### 2. निर्भरताएं (Dependencies) इंस्टॉल करें
सुनिश्चित करें कि आपके सिस्टम में Python 3.8 या उससे उच्च संस्करण स्थापित है। इसके बाद Flask इंस्टॉल करें:
```bash
pip install flask
```

### 3. एप्लीकेशन को रन करें
मुख्य फाइल `app.py` को चलाएं। रन होते ही यह स्वचालित रूप से डेटाबेस फ़ाइल `rajajicar.db` का निर्माण कर देगी:
```bash
python app.py
```

### 4. ब्राउज़र में टेस्ट करें
अपने वेब ब्राउज़र में नीचे दिए गए लोकल एड्रेस को ओपन करें:
```text
http://127.0.0
```
